8. 快速开始
================================================================================

1. 安装依赖:
   pip install -r requirements.txt

2. 启动服务器:
   python app.py
   或
   scripts\start.bat

3. 访问API文档:
   http://localhost:8000/docs

4. 运行测试:
   scripts\test.bat
